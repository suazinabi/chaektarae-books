# chaektarae-books

책타래 앱이 읽어 가는 파일.

- `books.json` — 유저와 책 (`{"users":[...],"books":[...]}`). 조금씩 들어오는 책은 `"more":true`, `"total":전체 조각 수`를 갖는다.
- `posts.json` — 예전 예약 작업이 올린 유저 트윗 (`{"posts":[{"id","u","x","ts"}]}`). 지금은 앱이 수아 API 키로 새 트윗을 직접 만든다.
- `catalog.json` — 서점 목록. 저작권 끝난 책의 제목·작가·소개·원문 주소(`src`). 못 만드는 책은 `"no":"이유"`.
- `src/<id>.json` — 책 전체를 미리 잘라 둔 원문 조각. 앱은 안 읽는다. 다음 부분을 이어 붙일 때 쓴다.
- `tools/` — 원문 뽑기(`ptext.py`), 조각 나누기(`chunk.py`), 검사(`check.py`), 올리기(`put.py`).

책은 이제 앱이 직접 만든다: 서점 책에 하트를 누르면 위키문헌에서 원문을 받아 조각을 나누고(`tools/chunk.py`와 같은 규칙), 다음 부분은 `src/<id>.json`이나 위키문헌에서 이어 붙인다. 유저마다 `taste`(책 취향)가 있어서 수아가 영업한 책을 같이 읽을지 정한다.
